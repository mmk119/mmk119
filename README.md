### Alzheimer's Detection from EEG Signals
`Python · Pandas · Scikit-learn`

Full pipeline on an 848,640 row EEG dataset from 16 scalp electrodes. Engineered 9 features covering regional averages, left right asymmetry and region ratios. Compared 5 classifiers under 3 fold cross validation and reached 79.4% accuracy with 0.88 ROC AUC on logistic regression. The tree models scored above 99%, which turned out to be data leakage from missing patient IDs. Reported bootstrap confidence intervals, F2 score and threshold analysis so the recall tradeoff stayed visible.
