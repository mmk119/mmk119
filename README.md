## Projects

### Sho el Zbde, Voice Note Digest
`PHP · Laravel · OpenAI API · Whisper · TypeScript · MCP` · [Repo](https://github.com/mmk119/Sho-el-zbde)

Turns a long voice note into a short digest: a summary, the questions asked of the listener, key details and the full transcript. Covered by 192 automated tests. Ships with a separate MCP server in TypeScript so Claude Desktop can call the app as a tool. Built with Claude Code.

### AutoStop, Intercity Ride Board (in progress)
`PHP · Laravel · MySQL · Leaflet`

A ride board for people already driving between Lebanese cities, like Sour to Beirut, so ride offers stop getting buried in WhatsApp groups. Drivers post trips and passengers can post requests too.

### Rally, AI Powered Court Booking Platform
`React · Tailwind · OpenAI API` · [Live](https://mmk119.github.io/Rally/)

Padel court booking with live availability and an analytics dashboard, plus an embedded assistant that books and cancels courts from plain language chat.

### CivicConnect, Volunteering Platform
`Node.js · Express · MongoDB · React` · [Repo](https://github.com/mmk119/CivicConnect)

My AUB final year project. REST API and database schema behind a platform with token based auth and role based access control for three roles, Admin, NGO and Volunteer, each with its own permissions and flows.

### Alzheimer's Detection from EEG Signals
`Python · Pandas · scikit learn`

Full pipeline on an 848,640 row EEG dataset from 16 scalp electrodes. Engineered 9 features covering regional averages, left right asymmetry and region ratios. Compared 5 classifiers under 3 fold cross validation and reached 79.4% accuracy with 0.88 ROC AUC on logistic regression. The tree models scored above 99%, which turned out to be data leakage from missing patient IDs. Reported bootstrap confidence intervals, F2 score and threshold analysis so the recall tradeoff stayed visible.

### MoodakLyom, AI Voice Journaling App
`Python · Whisper · Vosk` · [Repo](https://github.com/Zeinab2756/MoodakLyom)

Team project. I wrote the Python speech and transcription backend that feeds the Android journaling client.

### Brain Tumor Segmentation
`Python · UNet · Deep Learning`

Pixel level tumor segmentation on medical scans, end to end training and evaluation.
